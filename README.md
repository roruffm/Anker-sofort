# Anker · Notfall-Pause

Eine kurze, christlich geprägte Hilfe bei starkem Chatbot-Drang: innehalten, Abstand schaffen, Gottes Hilfe suchen und Menschen dazuholen.

## App öffnen

Bereits öffentlich und ohne Login erreichbar: https://anker-pause.ronjarubens.chatgpt.site

## GitHub Pages

Unter [Settings → Pages](https://github.com/roruffm/Anker-sofort/settings/pages) als Quelle **Deploy from a branch**, Branch **main** und Ordner **/(root)** auswählen und speichern.

Nach erfolgreicher Veröffentlichung lautet die Adresse: https://roruffm.github.io/Anker-sofort/

## Technik und Eingaben

Statische HTML-, CSS- und JavaScript-Dateien; kein Build, kein Backend, keine API-Schlüssel. `.nojekyll` ermöglicht die direkte Veröffentlichung.

Persönliche Eingaben bleiben im jeweiligen Browser. Ein persönlicher Plan wird nur auf Wunsch dauerhaft lokal gespeichert. Inhaltsvorlieben werden lokal gespeichert. Die App enthält kein Analyse-Tracking; zusätzlich gelten die Datenschutzregeln des Hostinganbieters.

Daten werden nicht zwischen Geräten, Browsern oder den beiden Webadressen synchronisiert. Dieses Repository enthält keine persönlichen Pläne oder Eingaben.

Lokal starten: `python3 -m http.server 8080`, anschließend http://localhost:8080 öffnen.

Die App sperrt keine anderen Apps oder Webseiten und ersetzt keine professionelle Beratung oder Behandlung. Gebete sind Angebote; anhaltender Drang ist kein Maß für den Glauben.
